This repository contains our group submission for the **Data Structures & Algorithms** course assignment.

## Problems Implemented

### Problem 54 – Call Stack Debugger Simulator

Simulates a program’s call stack during execution.

**Showcases:**

* Stack behavior for function calls and returns
* Variable scoping using parent frame traversal
* Stack overflow detection using a maximum depth
* Stack trace printing for debugging purposes

**Main Data Structures Used:**

* Stack
* Hash Map (for local variables)
* Linked references (for scope chain)

---

### Problem 21 – Real-Time Median Monitor

Maintains the median of a stream of numbers in real time.

**Showcases:**

* Efficient median calculation without sorting
* Balancing two heaps to maintain order
* Constant-time median retrieval

**Main Data Structures Used:**

* Max Heap
* Min Heap

---

### Problem 31 – VIP Restaurant Manager

Manages a restaurant waiting line with VIP handling and cancellations.

**Showcases:**

* O(1) insertion at front and back
* O(1) removal from any position
* Efficient lookup using name-based mapping

**Main Data Structures Used:**

* Doubly Linked List
* Hash Map

## How to Run

Make sure Python 3 is installed.

```bash
python call_stack_debugger.py
python two_heap_streaming.py
python vip_restaurant_manager.py
```

Each program runs independently and accepts commands via the terminal.
